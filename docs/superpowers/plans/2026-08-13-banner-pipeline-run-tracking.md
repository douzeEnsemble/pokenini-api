# Banner Pipeline Run Tracking (pokenini-api) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Persist the status of the `update_banners` GitHub Actions pipeline (workflow A run, icon-repo PR, workflow B run, resources-repo PR) so `pokenini-back` can poll and display it, mirroring the existing `ImagePipelineRun` feature exactly but as a fully separate entity.

**Architecture:** New entity `BannerPipelineRun` (same 14-field shape as `ImagePipelineRun`, `BaseEntityTrait` UUID id), `BannerPipelineRunRepository` (create/updateFields/findLatest), `BannerPipelineRunService`, `BannerPipelineRunController` at `/istration/banner-pipeline-runs` with the same 3 verbs (`POST`, `PATCH /{correlationId}`, `GET /latest`), `BannerPipelineRunPatch` DTO, `BannerPipelineRunResponse`/`BannerPipelineRunResponseFactory` for the read path. Deliberately duplicated, not parameterized — see the design spec's rationale (new entity over stretching an existing one, consistent with the `ActionLog` vs. `ImagePipelineRun` precedent).

**Tech Stack:** Symfony 8 / PHP ≥ 8.5, Doctrine ORM/Migrations, PHPUnit (`#[CoversClass]`, `#[Test]`), `Hautelook\AliceBundle\PhpUnit\RefreshDatabaseTrait`.

## Global Constraints

- `declare(strict_types=1)` in every file.
- Controller, DTO, Entity classes are `final`; Service/Repository stay non-`final` (project convention for mockability).
- 100% code coverage and 100% Mutation Score Index (`make coverage`, `make infection`) must both stay green.
- Every test class: `/** @internal */` + `#[CoversClass(TargetClass::class)]`.
- No changes whatsoever to `ImagePipelineRun`/`ImagePipelineRunRepository`/`ImagePipelineRunController`/`ImagePipelineRunService` or their tests — fully parallel, independent code.
- If `make coverage` reports a constructor/factory method in this feature as uncovered despite tests demonstrably calling it, this is a known, previously-verified false negative in this project's coverage tooling for this exact code shape (see `ImagePipelineRunResponseFactory::fromEntity()`'s docblock) — verify with a temporary side-effect statement before suppressing, then add `@codeCoverageIgnore` referencing that precedent; don't assume it's a real gap without checking.

```php
<?php

declare(strict_types=1);

namespace App\Repository;

use App\DTO\BannerPipelineRunPatch;
use App\Entity\BannerPipelineRun;
use Doctrine\Bundle\DoctrineBundle\Repository\ServiceEntityRepository;
use Doctrine\Persistence\ManagerRegistry;

/**
 * @extends ServiceEntityRepository<BannerPipelineRun>
 */
class BannerPipelineRunRepository extends ServiceEntityRepository
{
    public function __construct(ManagerRegistry $registry)
    {
        parent::__construct($registry, BannerPipelineRun::class);
    }

    public function create(string $correlationId): void
    {
        $run = new BannerPipelineRun($correlationId);

        $this->getEntityManager()->persist($run);
        $this->getEntityManager()->flush();
    }

    /**
     * @SuppressWarnings("PHPMD.CyclomaticComplexity")
     * @SuppressWarnings("PHPMD.NPathComplexity")
     */
    public function updateFields(string $correlationId, BannerPipelineRunPatch $patch): bool
    {
        $run = $this->findOneBy(['correlationId' => $correlationId]);

        if (null === $run) {
            return false;
        }

        if (null !== $patch->workflowARunId) {
            $run->workflowARunId = $patch->workflowARunId;
        }

        if (null !== $patch->workflowAStatus) {
            $run->workflowAStatus = $patch->workflowAStatus;
        }

        if (null !== $patch->workflowAConclusion) {
            $run->workflowAConclusion = $patch->workflowAConclusion;
        }

        if (null !== $patch->workflowAUrl) {
            $run->workflowAUrl = $patch->workflowAUrl;
        }

        if (null !== $patch->iconPrNumber) {
            $run->iconPrNumber = $patch->iconPrNumber;
        }

        if (null !== $patch->iconPrUrl) {
            $run->iconPrUrl = $patch->iconPrUrl;
        }

        if (null !== $patch->iconPrState) {
            $run->iconPrState = $patch->iconPrState;
        }

        if (null !== $patch->iconPrMergeCommitSha) {
            $run->iconPrMergeCommitSha = $patch->iconPrMergeCommitSha;
        }

        if (null !== $patch->workflowBRunId) {
            $run->workflowBRunId = $patch->workflowBRunId;
        }

        if (null !== $patch->workflowBStatus) {
            $run->workflowBStatus = $patch->workflowBStatus;
        }

        if (null !== $patch->workflowBConclusion) {
            $run->workflowBConclusion = $patch->workflowBConclusion;
        }

        if (null !== $patch->workflowBUrl) {
            $run->workflowBUrl = $patch->workflowBUrl;
        }

        if (null !== $patch->resourcesPrNumber) {
            $run->resourcesPrNumber = $patch->resourcesPrNumber;
        }

        if (null !== $patch->resourcesPrUrl) {
            $run->resourcesPrUrl = $patch->resourcesPrUrl;
        }

        if (null !== $patch->resourcesPrState) {
            $run->resourcesPrState = $patch->resourcesPrState;
        }

        $run->updatedAt = new \DateTime();

        $this->getEntityManager()->flush();

        return true;
    }

    public function findLatest(): ?BannerPipelineRun
    {
        /** @var ?BannerPipelineRun */
        return $this->createQueryBuilder('r')
            ->orderBy('r.createdAt', 'DESC')
            ->setMaxResults(1)
            ->getQuery()
            ->getOneOrNullResult()
        ;
    }
}
```
