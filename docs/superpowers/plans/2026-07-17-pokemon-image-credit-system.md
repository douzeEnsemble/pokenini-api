# Pokémon Image Credit System (pokenini-api) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Store, sync, and expose a per-Pokémon image credit (source name + URL) for each of the 4 image slots (small×regular, small×shiny, big×regular, big×shiny), embedded in existing Pokémon API responses and available as a deduplicated list via a new endpoint.

**Architecture:** A new `PokemonImageCredit` entity (one row per pokemon×size×shiny) is populated by extending `PokemonsUpdater`'s Google Sheets sync. Credits are joined into the 4 raw SQL queries that currently build `PokemonDataResponse` and exposed as 4 new nullable nested fields on it. A new `/credits` endpoint returns the deduplicated `{name, url}` list.

**Tech Stack:** Symfony 8 / PHP 8.5, Doctrine ORM + DBAL (raw SQL via `SqlFileLoader` and inline heredocs), PostgreSQL, PHPUnit.

**Related documents:** Design spec at `pokenini-web/docs/superpowers/specs/2026-07-17-pokemon-image-credit-system-design.md`. This is the first of three repo-scoped plans for this feature (pokenini-api → pokenini-back → pokenini-web), matching this workspace's convention of splitting cross-repo features into one plan per repo (see the 2026-07-14/15 image-pipeline feature's three plans for precedent). The pokenini-back and pokenini-web plans will be written after this one lands, since they depend on the exact field names/shapes produced here.

## Global Constraints

- `declare(strict_types=1)` in every PHP file.
- Entities: public properties only, no getters/setters, `final class`.
- Response DTOs (`src/DTO/Response/`): `final`, readonly, constructor-promoted, no default values (every caller passes every argument explicitly).
- Factories (`src/Factory/`): `final class`, static methods only.
- Repository/Service/Updater: **not** `final` (PHPUnit mocking).
- Controller: `final class`.
- Every test class: `/** @internal */` + `#[CoversClass(TargetClass::class)]`, PHPUnit `#[Test]` attribute on methods (not `test`-prefixed names, matching the newer factory/service tests in this repo).
- 100% code coverage (`make coverage`) and 100% Mutation Score Index (`make infection`) required before this is done. PHPStan level 9, Psalm strict, Deptrac clean.
- Deptrac layering: `Controller → Service → Repository`, `Factory` usable directly from `Controller` (see `TypesController`/`TypeResponseFactory` precedent), `Updater` alongside `Service`.
- All commands run via `make` inside the `php` Docker container (see repo `CLAUDE.md`).

- [ ] **Step 4: Implement `buildCredit()` and wire it into all 3 factories**

```php
    /**
     * @param array<string, mixed> $row
     */
    private static function buildCredit(string $prefix, array $row): ?ImageCreditResponse
    {
        $nameKey = "{$prefix}_credit_name";
        $urlKey = "{$prefix}_credit_url";

        if (empty($row[$nameKey]) || empty($row[$urlKey])) {
            return null;
        }

        /** @var scalar $name */
        $name = $row[$nameKey];

        /** @var scalar $url */
        $url = $row[$urlKey];

        return new ImageCreditResponse(name: (string) $name, url: (string) $url);
    }
```
